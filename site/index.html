Install

  1. 1

    Back up your boot image

    Keep a copy of the current boot partition so you can roll back.

  2. 2

    Verify the download

    Compare the file's SHA-256 with the value on its release card before flashing.

  3. 3

    Flash the zip

    Install *.zip from TWRP / OrangeFox on the boot partition, then reboot.

  4. 4

    Install the root manager

    KSU builds accept the BakaSU or KernelSU-Next manager. APatch and FolkPatch builds bundle their manager installer.

Flashing a custom kernel can brick your device. Unlock the bootloader, use a matching firmware base, and flash at your own risk.
